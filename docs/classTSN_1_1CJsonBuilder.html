bool TSN::CJsonBuilder::Val ( CJsonNode & node)

Escribe el valor de un nodo de json (CJsonNode) como valor del builder.

Parameters
[in]nodeNodo simple: UINTEGER, INTEGER, REAL, BOOLEAN, STRING o NULL
Returns
bool false si el nodo es de otro tipo (ARR, OBJ, KEY) o su valor no se pudo leer (no escribe nada en ese caso)
Note
Un STRING se copia TAL COMO esta escrito en el documento (bytes crudos entre comillas, con sus escapes originales y su UTF-8), sin volver a escaparlo (ValUWV).

CJsonBuilder * TSN::CJsonBuilder::ValU ( const uchar & v[],
int read_i = 0,
int count = WHOLE_ARRAY )

String CON escape desde bytes.

Parameters
[in]vBytes del texto
[in]read_iPosicion de v desde donde leer
[in]countCantidad de bytes a leer (WHOLE_ARRAY: todos)
Note
Cada byte se trata como un caracter Latin-1 (los >= 0x80 salen como u00XX por byte). Es lo previsto: sirve para texto ASCII o bytes en Latin-1; para texto UTF-8 con caracteres no ASCII usar ValS con un string de MQL5.
