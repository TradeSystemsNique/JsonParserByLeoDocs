Detailed Description

Interfaz de callbacks de CJsonParserStream: el parser avisa cada evento del json a medida que lo lee.

Se hereda y se implementan TODOS los metodos (son virtuales puros); luego se entrega a CJsonParserStream::SetCaller. Los eventos llegan en el orden del documento. Los strings, las keys y los numeros que no caben NO llegan como valor: llegan como (offset s, largo len) sobre los bytes crudos m_ctx.m_raw del stream, SIN desescapar. Para obtener el texto: CBSFLUnescape::MakeString<JsonUET>(m_ctx.m_raw, s, len, out) (desescapa) o CharArrayToString.

Warning
Los offsets s solo son validos DENTRO del callback: el buffer del stream se reutiliza (ver CJsonParserStream::CheckLimpieza). Copia lo que necesites.
Note
Dentro de un callback m_ctx apunta al stream que lo llama (por ejemplo m_ctx.LastErr() en OnError, o m_ctx.CurrentStack() para la profundidad).
En MQL5 los destructores son siempre virtuales (aunque no se declaren asi): el delete de SetCaller con del = true ejecuta el destructor de tu clase hija.
