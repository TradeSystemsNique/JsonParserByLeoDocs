Detailed Description

Tipos de nodo, tokens, banderas de estado, errores y tabla de caracteres del parser JSON.

Author
Niquel Mendoza
Copyright
2026, Niquel Mendoza
Date
2026

Este archivo tambien lo incluye la version C++ del parser (DLL, TSNPARSERIN_CPP_DLL): por eso las constantes son macros y enums simples. El parser se mueve como una maquina de estados: cada byte se convierte en un token con g_table_json_tokens y se comprueba contra una mascara de tokens permitidos (TSN_JSON_F_*) con ((1 << token) & estado) != 0.
