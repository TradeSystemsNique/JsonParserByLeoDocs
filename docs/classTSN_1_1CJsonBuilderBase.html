Detailed Description

Base de los builders: escribe json directo, como bytes UTF-8, a un buffer (sin DOM ni strings intermedios).

Lleva la posicion de escritura (m_pos), la capacidad (m_cap) y una pila de niveles que le dice si hace falta una coma antes del siguiente elemento: las comas se ponen SOLAS. El buffer crece solo cuando hace falta.

  • Estructura: Obj() / EndObj() y Arr() / EndArr().
  • Valores simples: Val(...) y Null(). Dentro de un objeto cada valor va despues de una clave (Key / KeyWV de las clases derivadas).
  • Strings y claves: en las clases derivadas, que escapan segun el destino: CJsonBuilder (json normal) o CJsonBuilderStr (json dentro de un string json). Resultado: Build() (string) o Build(uchar&) / m_buf + m_pos (bytes, sin copias).
    Note
    Obj, EndObj, Arr, EndArr, Val y Null devuelven CJsonBuilderBase*, no la clase derivada: sirven para encadenar entre ellos, pero NO se puede encadenar Key ni ValS despues (esos devuelven la clase derivada y si se pueden encadenar entre si: b.Key("a").ValS("x")).
    Warning
    No valida la estructura: un EndObj sin Obj, un valor en un objeto sin clave o pasarse de JSONBUILDER_MAX_STACK niveles no da error, solo json invalido o acceso fuera de rango.

◆ GetSnapshot()

__forceinline void TSN::CJsonBuilderBase::GetSnapshot ( JsonBuilderSnapshot & snap)

Guarda el estado (posicion, nivel y coma pendiente) para poder deshacer lo que se escriba despues.

Es barata: no copia bytes. ApplySnapshot vuelve m_pos y el nivel a ese punto, descartando lo escrito desde entonces. Util para probar escribir algo y volver atras si falla. No cubre cambios en bytes ya escritos antes de la foto.

◆ GetSnapshotF()

Note
