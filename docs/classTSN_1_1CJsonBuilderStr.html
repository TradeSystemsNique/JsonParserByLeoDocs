Detailed Description

Builder de un json "para meter dentro de un string json": las comillas de claves y strings salen escapadas y las barras duplicadas.

Note
A diferencia de CJsonBuilder no tiene Val(CJsonNode&) ni ValidJson; los numeros, booleanos y null son los de CJsonBuilderBase.
