Detailed Description

Parser JSON en streaming: se le da el documento por trozos y avisa por callbacks (ITsnJsonParserStream), sin guardar cinta ni DOM.

Uso:

  1. SetCaller(tu_implementacion, true).
  2. Por cada trozo de bytes: opcionalmente CheckLimpieza(), copiar los bytes nuevos a m_raw a partir de m_pos, sumar su cantidad a m_len y llamar ParseSreamSax() (ejemplo completo en el README, seccion "Stream-With SAX Parse"). ParseSreamSax procesa todo lo disponible. Devuelve true cuando agota los datos (hace falta mas, o el documento termino) y false si hubo un error (ya se llamo a OnError). Al terminar un documento o fallar queda listo para uno nuevo. Los numeros que no se pueden representar exactos se entregan por OnBigInteger / OnBigDecimal para que decidas que hacer. Hereda de CBaseLanFormat: m_raw, m_len, m_pos y m_offset son publicos y los maneja quien alimenta el stream.
    Note
    Minimo un byte nuevo en cada llamada a ParseSreamSax (no llamarla sin datos nuevos).
    Como en Parse, la raiz debe ser un objeto o un array.

◆ ParseSreamSax()

bool TSN::CJsonParserStream::ParseSreamSax ( void )

Procesa los bytes disponibles en m_raw (desde m_pos hasta m_len) y dispara los callbacks.

Returns
bool true: se agotaron los datos (hace falta otro trozo) o el documento termino (OnEndDocument); false: error (OnError ya se llamo, ver LastErr)
Note
Minimo un byte nuevo por llamada. Un valor partido entre trozos (string, numero, true / false / null) se completa en la llamada siguiente.
