Detailed Description

struct base para un nodo de json

Esta clase sirve como nodo base que represennta un nodo de un objeto Json Es un handle liviano a un valor de la cinta de un CJsonParser (copiarlo es gratis); el acceso (operator[], At, Begin*, Size, HasKey, GetAs...) viene de CNodeSFLBase (BasesParserSLan\Src\Node\NodeBase.mqh) y aqui se agregan las conversiones propias de json: string, enteros, real, MqlParam, null y las keys. Un nodo invalido o vacio (EMPTY_NODE) nunca falla: las funciones devuelven su valor por defecto. Los tipos de nodo son ENUM_JSON_VTYPE (JsonCore\JsonDefines.mqh): ARR, OBJ, UINTEGER, INTEGER, REAL, BOOLEAN, STRING, NULL y KEY. Las keys solo se obtienen desde un iterador de objeto (Key()) o AtObjKey.

Parameters

Note

Warning
en caso el tipo del nodo no sea un "tipo" simple, da false
Returns
true en caso de exito, false si fallo

El valor se toma segun param.type, con las mismas conversiones que ToInt / ToDouble / ToString / ToBool: bool, enteros (char a long) y float/double van a integer_value / double_value; color y datetime se parsean desde el texto del nodo; string y cualquier otro tipo van a string_value.

Note
"Tipo simple" se decide con CJsonParser::s_dtype_to_str: UINTEGER, INTEGER, REAL, BOOLEAN y STRING; ARR, OBJ, NULL y KEY devuelven false.
